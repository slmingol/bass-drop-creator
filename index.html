Quick start guide
1
Pick a note

Select any note (C–B) and octave (1–4). The Hz display updates live.

2
Transpose to Note

Scales all frequency parameters proportionally to the new note, preserving the preset's character and octave relationships.

3
Shape each layer

Sub = constant tone. Sweep = pitch glide (the "drop"). Punch = attack click. Rumble = filtered noise. Body = warmth.

4
Drive & Gain

Drive adds tanh saturation (1 = clean, 3+ = heavy). Gain trims post-saturation output. Keep ≤ 1.0 to avoid clipping.

5
Preview

Plays in browser via Web Audio API. Regenerates automatically when params change.

6
Download WAV

Exports a 16-bit PCM mono .wav at the selected sample rate (44.1 or 48 kHz), named after the selected note.
